# Next.js + React Three Fiber (R3F)

A minimal starter template demonstrating how to integrate **React Three Fiber** and **Three.js** inside a **Next.js** (App Router) project with client-side dynamic rendering.

## Features

- **Next.js (App Router)** with TypeScript
- **React Three Fiber (`@react-three/fiber`)** & **Three.js**
- **SSR-safe Canvas**: Dynamically imported 3D scene avoiding server-side WebGL issues
- **Interactive 3D Scene**: Rotating mesh with hover and click state interactions
- **Tailwind CSS** for layout styling

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   # or
   bun install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   # or
   bun dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser to view the 3D scene.
